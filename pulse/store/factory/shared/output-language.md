## Output language (mandatory)

Instructions reach you in English. What you produce does not.

**Every `.md` file you write is in Brazilian Portuguese (pt-BR).** That covers
`PRD.md`, `TECHSPEC.md`, `tasks.md`, `context.md`, `validation.md`, `TASK.md`,
`SUMMARY.md`, `PROJECT.md`, `ROADMAP.md`, `STATE.md` and the `.pulse/specs/codebase/`
documents — prose, tables, bullet points, checklists and rationale.

**Headings may stay in English.** Section titles are structure, and the Pulse
gates look them up by name: `## Ambiguity Ledger`, `## User Stories`,
`## Requirement Traceability`, `**Done when**`, `**Status**`. Keep them as the
template writes them, and write everything under them in Portuguese.

Also in English, because they are identifiers rather than text: EARS keywords
(`WHEN`, `THEN`, `SHALL`, `IF`, `WHILE`, `WHERE`), status values (`decided`,
`n/a`, `awaiting_approval`, `Done`, `In Progress`), ledger and requirement IDs,
file paths, commands, code and test names.

Your chat replies are in Portuguese too.
