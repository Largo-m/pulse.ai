# Pulse CLI

Cliente terminal do Pulse Engine — **somente TUI Textual**.

## Entrypoint

```bash
pulse
pulse init      # onboarding na TUI
pulse doctor
pulse config
pulse daemon start|stop|status
```

Código: [`pulse/cli.py`](../pulse/cli.py), [`pulse/tui/`](../pulse/tui/), [`pulse/client/`](../pulse/client/).
