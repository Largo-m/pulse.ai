# ADR-001: Hybrid Cursor Credential Entry via Shared Settings Surface

## Status

Accepted

## Date

2026-05-22

## Context

PRD agent runs require a valid Cursor Cloud Agents API key. The orchestrator already surfaces remediation copy and a banner CTA, but there is no working in-app configuration path. Product requires a single configuration experience reachable from the settings gear and from the connection banner so admins are not sent through divergent flows.

## Decision

Implement one shared Cursor integration settings surface opened from both the orchestrator top-bar settings control and the connection banner CTA. The surface handles register, test, rotate (replace), and remove for a single workspace key on the local device. PRD execution remains gated by existing connection preflight until status is `connected`.

## Alternatives Considered

### Alternative 1: Separate banner wizard vs. settings page

- **Description**: Lightweight inline wizard on the banner and a fuller settings page from the gear.
- **Pros**: Could optimize each entry point independently.
- **Cons**: Two flows to maintain; contradicts PRD hybrid requirement and increases confusion.
- **Why rejected**: Duplicates validation and copy; violates single-surface goal.

### Alternative 2: External-only configuration (env file / CLI)

- **Description**: Document key setup outside the app.
- **Pros**: Minimal UI work.
- **Cons**: Fails PRD goals; banner CTA becomes a dead end; poor desktop UX.
- **Why rejected**: Does not close the product gap described in the PRD.

## Consequences

### Positive

- One mental model for admins; gear and banner stay consistent.
- Reuses existing preflight, gate, and secure storage contracts.

### Negative

- All settings UX complexity concentrates in one modal implementation.

### Risks

- Placeholder handlers must be fully wired or discovery fails — mitigate by replacing `onPlaceholder` for settings only in this delivery.

## Implementation Notes

Wire `onOpenCursorSettings` from `WorkflowPrdWorkspace` and the top-bar settings icon to the same `show` helper for the settings modal.
