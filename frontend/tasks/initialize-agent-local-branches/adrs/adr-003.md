# ADR-003: InitializeAgentBranchesCubit in OrchestratorComposition

## Status

Accepted

## Date

2026-05-18

## Context

The initialize-agent modal today holds branch state in `ValueNotifier`s with hardcoded branch names. The PRD requires loading, error, and non-Git UI states that align with existing orchestrator patterns (`RecentProjectsCubit`, `ImportFlowCubit`).

## Decision

Introduce **`InitializeAgentBranchesCubit`** + **`InitializeAgentBranchesState`** under `presentation/bloc/`, wired in **`OrchestratorComposition.create()`** and exposed via **`MultiBlocProvider`**.

- Cubit depends on **`ListLocalGitBranchesUseCase`** only (not the git service directly).
- Modal calls `cubit.loadForProject(absolutePath)` on open and when project selection changes.
- Modal reads state via `BlocBuilder` / `BlocSelector`; user branch overrides stored in cubit state after successful load.

## Alternatives Considered

### Alternative 1: Ephemeral Cubit in `showInitializeAgentModal`

- **Description**: `BlocProvider` created when the dialog opens, disposed on close.
- **Pros**: No long-lived cubit in app scope; state scoped to modal lifetime.
- **Cons**: Extra provider nesting; diverges from existing composition pattern; harder to test from page level.
- **Why rejected**: Stakeholder preferred central registration in `OrchestratorComposition`.

### Alternative 2: `ValueNotifier` + use case in `StatefulWidget`

- **Description**: Keep local notifiers; invoke use case from `initState` / project listener.
- **Pros**: Fewer files.
- **Cons**: Duplicates loading/error state machine; inconsistent with project Bloc rules.
- **Why rejected**: Violates established orchestrator presentation pattern.

## Consequences

### Positive

- `bloc_test` coverage for load transitions, cancellation on rapid project switch, and detached HEAD edge cases.
- Modal widget stays mostly declarative.

### Negative

- Cubit must be reset when modal closes to avoid stale branch list on next open (`reset()` in modal `dispose` or when dialog completes).

### Risks

- Concurrent loads if user switches project quickly — mitigate with generation token / ignore stale responses in cubit.

## Implementation Notes

- Add `loadGeneration` or compare `requestedPath` on emit to drop outdated async results.
- Call `reset()` when modal route is popped.
