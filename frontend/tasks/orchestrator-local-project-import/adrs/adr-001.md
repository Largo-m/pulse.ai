# ADR-001: Contextual Recent Projects Sidebar with Active Selection

## Status

Accepted

## Date

2026-05-15

## Context

Tech leads manage multiple local repositories. The orchestrator must show recent projects without changing the first-run empty experience. The sidebar must support active selection for future agent binding without opening a workspace in MVP.

## Decision

- Hide the sidebar when zero projects exist; keep full-width empty state unchanged.
- Show the sidebar when one or more projects exist.
- List up to ten projects, most recent first.
- Clicking a row sets active selection (non-color-only visual state per design system).
- Re-importing the same folder path dedupes, updates recency, and moves the entry to the top.
- Clicking a row does not open file tree, editor, or agent session.

## Alternatives Considered

### Alternative 1: Always-visible sidebar

- **Description**: Show an empty sidebar with CTA when no projects exist.
- **Pros**: Consistent chrome; import CTA always in the same zone.
- **Cons**: Distracts first-time users; conflicts with PRD empty-state goal.
- **Why rejected**: PRD requires unchanged empty state until first import.

### Alternative 2: Modal project switcher instead of sidebar

- **Description**: Command-palette or dialog to switch projects.
- **Pros**: Saves horizontal space.
- **Cons**: Lower at-a-glance awareness for multi-repo users.
- **Why rejected**: Persona needs persistent visible context.

## Consequences

### Positive

- Clear multi-repo context without workspace UI.
- Empty state preserved for onboarding.

### Negative

- Layout shift when first project is imported.
- No remove/pin in MVP; cap may frustrate power users.

### Risks

- Users expect click to "open" code — mitigate with copy framing selection-only until Phase 2.

## Implementation Notes

- Section title and strings in `OrchestratorStrings` (PT-BR).
- Add `PulseDimensions` token for sidebar width before UI implementation.
- Widget: `RecentProjectsSidebar` + `RecentProjectListTile` under `presentation/widgets/`.
