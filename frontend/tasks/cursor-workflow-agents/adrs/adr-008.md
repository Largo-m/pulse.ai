# ADR-008: Inline PRD Markdown Editing Before Approval

## Status

Accepted

## Date

2026-05-20

## Context

PRD open question #5 asked whether users edit the PRD in Pulse or only via agent re-run. Review flow requires human approval; tech leads may need small corrections without another agent cycle.

## Decision

Provide an **inline markdown editor** in the PRD review workspace when status is `draft` or `pendingApproval`. Saving edits updates `prd.md` on disk and records `lastEditedAt` / `editedByUser` in Hive approval metadata. **Approve** persists the edited version as the approved artifact. Agent-generated drafts remain the default starting point; re-run after reject still replaces draft unless user saved edits are merged per run policy (new run overwrites draft file; user warned if unsaved edits exist).

## Alternatives Considered

### Alternative 1: Read-Only Review (Agent-Only Changes)

- **Description**: Approve or reject only; no manual edit.
- **Pros**: Simpler UI; single source of truth from agent.
- **Cons**: Extra agent runs for typos; higher cost and cycle time.
- **Why rejected**: Stakeholder selected inline edit during TechSpec clarification.

### Alternative 2: Defer Editor to Post-MVP

- **Description**: Ship read-only MVP first.
- **Pros**: Smaller initial UI scope.
- **Cons**: Misses clarification outcome in same release.
- **Why rejected**: Explicit MVP inclusion.

## Consequences

### Positive

- Reduces reject/re-run churn for minor fixes; supports discoverability of final approved text in Pulse.

### Negative

- Must handle dirty-state, unsaved navigation, and overwrite on new agent run.
- Editor accessibility and PT-BR chrome strings required.

### Risks

- Divergence between approved PRD and what agent last produced; mitigation: store `sourceRunId` on artifact metadata and show "editado pelo usuário" badge in review header.

## Implementation Notes

Use Cubit for editor dirty state; no `setState`. Strings in `OrchestratorStrings` or `PrdWorkflowStrings`. Unit tests for save + approve with edited body.
